# smolagents 开源框架映射表

| 我手写的 tool_agent.py | smolagents 框架里对应什么 |
| :--- | :--- |
| `TOOLS` 字典 | 用 `@tool` 装饰器将带类型注解的函数变成 Tool，传给 `ToolCallingAgent` |
| `SYS` 提示词要求输出 JSON | 框架原生的 tool calling 机制，提示模板在 yaml 中管理 |
| `parse_calls` 剥围栏与正则提取 | 框架内部解析 `ChatMessageToolCall`，无需手写正则 |
| `TOOLS[name]` 执行 + 异常兜底 | 框架按 `Tool.inputs` 校验参数后调用，结果进入多步消息 |
| `run()` 手动回喂 + `max_calls` 收口 | `MultiStepAgent` 的多步循环，框架自动管理步数与停止条件 |
