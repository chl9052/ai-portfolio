# W10 预习：Function Calling / MCP / API 辨析

1. **Function Calling（模型侧机制）**：大模型根据用户意图，自主判断并输出“我要调用哪个函数、参数是什么”，但模型不直接执行代码，执行由外部程序完成。
2. **MCP（工具侧协议）**：Model Context Protocol，是一种标准化的通信协议。它解决的是不同外部工具、数据源如何以统一的格式接入大模型的问题，是工具方的接口标准。
3. **普通 API 调用**：传统的程序间通信，由开发者写死代码逻辑去请求某个接口，没有大模型的“智能决策”参与。

**希望MCP帮我接上的2个外部工具**：
- **教务系统查询**：获取学生的平时成绩与考勤情况。
- **生词本同步**：将学生查过的生词自动同步到他的专属云笔记中。
