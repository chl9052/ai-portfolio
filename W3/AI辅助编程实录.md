# 第三周 AI 辅助编程实录

## 一、本周任务目标

本周学习 AI 辅助基础 Python 编程，完成一个**词汇查询工具 vocab_tool.py**。
实现功能：读取词汇表、查询单词、新增单词、保存更新文件。
我通过三轮提示词迭代，从不会代码到完成可运行程序。

## 二、三轮提示词迭代记录

### 第一轮：零基础模糊提问

**提问：**
帮我写一个查单词的 Python 代码。

**输出问题：**
代码非常简陋，没有文件读取功能，不能保存单词，没有新增词汇功能，无法用于作业，结构混乱、不能运行。

**不足：**
需求太宽泛，没有说明需要 CSV 文件、保存功能、查询功能、新增功能，AI 无法产出可用成品。

### 第二轮：明确功能需求

**提问：**
帮我写一个 Python 词汇工具，可以读取 csv 单词表，可以查询单词，可以添加新单词，最后保存文件。

**改进效果：**
代码出现读取、查询、添加、保存基本框架，功能齐全。

**剩余问题：**
代码没有容错，输入错误会直接报错；没有中文提示界面，使用体验差；没有换行排版，阅读困难。

### 第三轮：标准化、作业级精准提示词（最终版）

**提问：**
帮我写一份大学生入门水平的 vocab_tool.py 单词管理程序，要求：

1. 读取本地 csv 词汇文件
2. 实现：查询单词、新增单词、展示全部词汇
3. 加入异常处理，防止输入错误报错崩溃
4. 界面中文提示清晰、排版整洁
5. 修改后自动保存到原文件
6. 代码注释清晰、适合上交作业

**最终效果：**
代码完整可运行、无报错、功能全部达标、界面友好、注释规范，完全满足本周作业要求，可以直接提交。

## 三、迭代收获

第三周编程学习让我体会到：**AI 编程不是直接抄代码，而是靠精准需求得到稳定代码**。
一开始模糊提问只能得到残缺代码，随着我不断细化功能、限制格式、增加容错要求，代码质量大幅提升。

我学会了写编程提示词的关键：**写清功能、格式、容错、用途、难度**。
以后遇到不会的小程序，我可以通过多轮迭代，从零完成完整、规范、可上交的 Python 作业。
