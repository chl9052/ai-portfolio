## 适用说明
备课使用，输入简略想法，一键扩充完整教案，适合汉教备课。

## 最佳示例
输入要点：语法“把”字句，HSK2，45分钟课
输出：
# 《“把”字句》教案
教学对象：HSK2水平留学生
课时：45分钟
教学目标：
1.认知：理解“把”字句含义；
2.能力：会用【主语+把+宾语+动词+结果】造句。
重点：“把”字句基本结构；难点：动词必须带结果。
教学流程：
1.导入（5min）图片展示：我把杯子洗干净了。
2.讲解（15min）公式+例句。
3.练习（20min）替换练习、看图造句。
4.小结+作业（5min）
作业：用把字句写3个句子。
