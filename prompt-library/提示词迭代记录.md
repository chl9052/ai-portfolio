# 提示词迭代记录
## 目标任务
为对外汉语教学设计AI提示词，用来生成教案、课堂活动、作文批改、词汇筛查、语法讲解等教学素材。

### 迭代1（初始版本）
提示词：帮我写对外汉语教案。
问题描述：输出内容简略，没有固定格式，缺少例句、课堂练习，产出不稳定。

### 迭代2（优化版本）
提示词：你是对外汉语老师，写一份教案，包含教学目标、步骤、例句。
改进：增加了基础框架，但缺少HSK等级、课堂注意事项，示例不够规范。

### 迭代3（最终版本，现在使用）
提示词：你是对外汉语XX方向老师，按照固定结构输出，包含适用水平、目标、材料、步骤、示例、易错点。
改进：
1. 固定输出结构，方便直接用于微课作业
2. 增加HSK分级，贴合留学生水平
3. 加入正误例句对比，满足课程作业要求
4. 增加最佳示例，AI输出风格统一

## 总结
多次调整提示词，限定角色、输出格式、适用对象，让AI生成的教学材料更规范，满足对外汉语教学作业需求。
