# 第四周 密钥安全自查表

## 一、本周学习内容

本周学习 API 密钥调用、机器人接口使用，重点掌握 **密钥安全、隐私保护、代码规范**，防止敏感信息泄露。

## 二、个人安全自查（全部达标）

### 1. 密钥未硬编码

我没有将 API Key、Secret、Token 直接写在 `.py` 代码正文里，不会随代码上传公开。

### 2. 不公开上传敏感信息

所有含密钥的配置文件、环境变量文件均未上传仓库，保证外网无法查看个人私密密钥。

### 3. 使用环境变量方式调用密钥

通过系统环境变量读取密钥，代码只读取、不存储、不显示密钥明文，安全规范。

### 4. 代码无明文泄露

本次 week4_api_bot.py 完整检查：

- 无密钥明文
- 无个人隐私信息
- 无账号、手机号、邮箱泄露风险

### 5. 仓库公开安全

我的仓库为公开仓库，我已确认：**所有可公开文件均不含个人私密数据**，符合课程安全要求。

## 三、风险自查总结

我检查了全部文件、日志、聊天记录、代码内容，确认：
**无密钥泄露、无隐私泄露、无违规公开内容。**

## 四、本周学习收获

我理解了 API 密钥属于最高隐私权限，一旦泄露会被他人盗用、消耗额度、产生风险。
今后写接口代码，我将坚持三条原则：

1. 密钥绝不写死在代码里
2. 私密配置不上传仓库
3. 每次提交前自查敏感信息

养成安全、规范、严谨的 AI 编程习惯。
