# Ollama 本地部署记录

## 一、 安装步骤
1. 下载并双击运行 Ollama 离线安装包（Windows版）。
2. 安装完成后，任务栏出现羊驼图标，服务启动成功。
3. 打开命令行（CMD），输入 `ollama pull qwen2.5:0.5b` 下载模型（大小约397MB）。
4. 输入 `ollama run qwen2.5:0.5b` 成功进入对话模式。

## 二、 模型选型与理由
- **所选模型：** `qwen2.5:0.5b`
- **选型理由：** 我的电脑内存是 **16 GB**。根据讲义要求，16GB 内存首选 4b（Q4量化档），但由于当前可用内存较少，为了确保运行流畅，仍先选用 0.5b 档位建立手感（体积仅397MB，运行速度极快，不卡顿）。后续作业中会再拉取 4b 模型进行对比测试。

课后作业 1：Ollama 官方文档学习笔记
通过阅读 Ollama 官方文档的 Model 管理与 API 两节，我总结了 3 条以前不知道的重要用法：

使用 ModelFile 自定义专属模型： 可以创建一个文本文件，在里面写死系统提示词（System Prompt）和参数（如 FROM qwen2.5:0.5b），然后通过 ollama create 命令生成专属模型，不用每次对话都重新输入背景要求。

通过 API 精确调节 temperature 参数： 在调用 API 时，可以传入 temperature（温度值）。设为 0.1，模型回答会非常严谨固定（适合出题）；设为 0.8，回答就会更有创意（适合写文章）。

通过环境变量控制内存占用（OLLAMA_KEEP_ALIVE）： 模型默认会在内存里保留 5 分钟。可以通过设置环境变量 OLLAMA_KEEP_ALIVE=0，让模型回答完立刻从内存卸载，防止电脑卡顿。

课后作业 2：不同量级模型质量对比与判断
测试对象：qwen2.5:0.5b（约 397MB） vs qwen3:4b（约 2.5GB）

质量对比：0.5b 模型虽然速度极快，但在复杂任务（如出题）时极易出现“幻觉”和无中生有；4b 模型由于参数更大且经过 Q4 量化，逻辑能力和指令遵循能力有显著提升。

内存与判断：我的电脑是 16GB 内存，跑 0.5b 毫无压力，但跑 4b 会多占用约 2-3GB 的内存空间。结论：如果是对格式要求高、需要质量的批改或教案生成任务，4b 多占的内存绝对是值得的（准确率高）；如果是简单批量任务，0.5b 的速度优势更明显。

课后作业 3：离线部署复盘
如果去无网的乡村学校教室部署，我会这样准备：

离线包： 提前用一个容量大的 U 盘，下载好 Ollama 的 Windows 离线安装包，以及 qwen2.5:0.5b 的离线模型包。

模型选择： 必须选 0.5b 等轻量级模型。因为乡村学校的旧电脑内存大概率只有 8GB 甚至更低，4b 以上模型会直接让电脑死机。

内存预算： 不需要购买昂贵的云服务器，只需准备普通台式机即可，能省下大笔 API 调用费用。

## 补充：术语与边界认知

- **量化（Quantization）：** 是把模型权重从高精度（如16位浮点）压成低精度（如4位整数）。它管的是“模型能不能装进你的电脑”，能大大减少内存占用，但代价是稍微损失一点精度。
- **MCP（模型上下文协议）：**是一种用于让模型连接外部工具和数据的通信协议。它主要解决“模型是否能够使用外部工具”的问题。
- **边界认知：** 学生作文、未公开教案、成绩等包含隐私的数据绝对不能上云；公开课文、通用知识可以上云。即使是云端，也必须先脱敏（删掉姓名、学号）。
