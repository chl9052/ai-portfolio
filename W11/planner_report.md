# Planner 规划智能体实验报告
## 1. 实验目的
实现任务规划智能体，接收用户复杂任务，自动拆解为有序子任务，分析任务依赖关系，生成可执行计划。

## 2. 代码逻辑说明
1. 接收用户输入的目标任务（默认示例：愚公移山）
2. 调用大模型对任务进行理解、拆解
3. 输出结构化子任务，标注先后顺序
4. 结合RAG检索（week08模块），读取参考资料辅助规划
5. 支持本地Ollama模式、云端API模式两种运行方式

## 3. 环境说明
程序依赖：langchain、chromadb、langchain-chroma、langchain-ollama等。
本机配置时出现模块导入异常，向量库chromadb环境搭建困难，未能完整运行出模型输出。

## 4. 预期输出示例（愚公移山）
用户任务：愚公移山
智能体规划：
1. 评估太行、王屋二山的规模与搬运难度
2. 组织家人一起参与挖土凿石
3. 把土石搬运到渤海之尾
4. 日复一日坚持劳作
5. 山神上报天帝，天帝派大力神搬走大山

## 5. 实验思考
规划智能体难点：
- 识别子任务之间的先后依赖
- 处理任务中的不确定条件、异常情况
- 支持中途修改目标、重新规划
- 结合检索工具，利用外部资料辅助制定计划
