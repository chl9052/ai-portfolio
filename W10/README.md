# 基于FastMCP的MCP工具调用演示
## 项目简介
本项目基于FastMCP框架搭建MCP服务，结合智谱GLM-4-Flash大模型实现LLM工具调用。项目分为服务端和客户端两个文件，大模型能够自主判断、调用加法工具完成算术计算。
